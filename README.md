# CodeCoach HTML

Tells kids and parents what is wrong with their HTML webpages in plain words.
Finds unclosed tags, broken images, empty links, and quotation bugs without requiring a browser DevTools window.

```
START_GUI.bat           open the visual kid dashboard
RUN_CodeCoach_HTML.bat  watch a folder in console
RANDOM_QUESTION.bat     play web coding trivia for stars & badges
python htmlcoach.py page.html
```

Offline. Zero third-party dependencies (built with Python standard library).
